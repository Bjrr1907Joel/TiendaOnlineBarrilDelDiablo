## Publicación

1. Descomprime el ZIP.
2. En GitHub abre tu repositorio.
3. Selecciona **Add file > Upload files**.
4. Sube todos los archivos y carpetas manteniendo esta estructura.
5. Pulsa **Commit changes**.
6. Espera entre 1 y 3 minutos para que GitHub Pages se actualice.
