CÓMO AGREGAR UNA FOTO DE PRODUCTO
1. Busca el código del producto en GUIA_IMAGENES_PRODUCTOS.csv.
2. Nombra la imagen con ese código. Ejemplo:
   7759291179126.png
3. Sube la imagen a:
   img/productos/
4. La tienda la mostrará automáticamente.
